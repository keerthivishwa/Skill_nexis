# INKSPACE: React Blog UI

A responsive editorial-style blog built with React, Vite and plain CSS. Posts come from a local JSON file, with live search and category filtering.

## Run the project

```bash
npm install
npm run dev
```

Open the `http://localhost:5173` link shown in the terminal.

## Build for production

```bash
npm run build
npm run preview
```
